APK Packager, Backup Vault & Developer Sandbox

Build signed offline packages, backup JSON data, or inject synthetic test data

1. Instant Offline Standalone App (.html)

Download the complete self-contained offline app file. It launches directly into the KRONOS workspace on Android Chrome/WebView or any desktop browser with zero internet required.

2. Build Signed Android APK & Electron Desktop App

Package your downloaded kronos-flow-studio-offline.html into a Self-Signed Android APK (V1+V2 signed so Android never shows an unsigned package error) OR a Standalone Electron Desktop App: 

# === OPTION A: 1-CLICK ELECTRON DESKTOP APP (Win / Mac / Linux) ===
mkdir kronos-studio && cd kronos-studio
npm init -y && npm install --save-dev electron electron-builder
# Place downloaded index.html in folder, then run:
npx electron-builder --dir

# === OPTION B: SIGNED ANDROID APK (Zero Install Errors) ===
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "Kronos Flow Studio" "com.kronos.flowstudio" --web-dir .
npx cap add android && npx cap copy
# Generate V1+V2 Keystore & Sign APK automatically:
keytool -genkey -v -keystore kronos-release.keystore -alias kronos -keyalg RSA -keysize 2048 -validity 10000 -storepass kronos123 -keypass kronos123 -dname "CN=Kronos Studio, O=FlowOS, C=US"
cd android && ./gradlew assembleRelease
apksigner sign --ks ../kronos-release.keystore --ks-pass pass:kronos123 app/build/outputs/apk/release/app-release-unsigned.apk
